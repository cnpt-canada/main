practices

Three practices. A project can use one of them or all three.

What cnpt does.

Information system design for organisations. We audit existing systems and data structures, redesign how information moves through the business, and identify where AI can be applied. Delivered as system maps, data models, and an implementation roadmap.

System mapsData modelsAI adoptionInternal tools

Human-centred design for consumer services. We run user research, map the customer journey, and design the interface and service flow. Delivered as research findings, journey maps, and a working UI system.

ResearchJourney mapsService flowsUI systems

Design fabrication for physical products and spaces. We take an approved design into production — material selection, detail drawings, tolerances, and coordination with suppliers through to finished output.

Detail designMaterialsFabricationProduction handover

All three practices share one team and one method, so a project can move between them without changing vendors.
